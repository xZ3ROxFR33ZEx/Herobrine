# Herobrine
This is a mod for Minecraft's CurseForge mod launcher, designed to stay true to the vanilla version. Offers new bosses, weapons and a new armor set. <br>
This mod is still in active development, please be patient while improvements are underway! <br>
<br>
Includes: <br>
Herobrine Boss <br>
Notch Encounter <br>
Bedrock armor set <br>
And more! <br>
