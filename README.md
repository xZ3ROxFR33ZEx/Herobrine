# Herobrine
This is a mod for Minecraft's CurseForge mod launcher, designed to stay true to the vanilla version. Offers new bosses, weapons and a new armor set. 
This mod is still in active development, please be patient while improvements are underway!

Includes:
Herobrine Boss
Notch Encounter
Bedrock armor set
And more!

Thank you for all of your support!
